# Kalvettu Builders · கல்வெட்டு

Website for Kalvettu Builders: house construction in Dharmapuri, Krishnagiri and Bengaluru with published per sq.ft rates, itemised packages, a cost calculator, stage-wise payments, interactive 3D house designs and 17 area pages.

Live: https://saikumarm21999-gif.github.io/kalveedu-builders/

## Structure
- `index.html` – home page (3D viewer, packages, calculator, payments, approvals, FAQ, contact)
- `<area>/index.html` – one SEO landing page per area (e.g. `house-construction-in-pennagaram/`)
- `assets/` – shared stylesheet, favicon, social sharing image
- `sitemap.xml`, `robots.txt`, `404.html`
